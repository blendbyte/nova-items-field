# Security Policy

## Supported Versions

| Version | Nova | Supported          |
| ------- | ---- | ------------------ |
| 2.x     | 5    | :white_check_mark: |
| 1.x     | 4    | :x:                |

Only the latest 2.x release receives security updates.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately via:

- [GitHub Security Advisories](https://github.com/blendbyte/nova-items-field/security/advisories/new)
- Email: [security@blendbyte.com](mailto:security@blendbyte.com)

Include the affected version, a description of the issue, and steps to reproduce.

We aim to acknowledge reports within 5 business days and will keep you informed of the fix timeline.
